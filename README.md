# 🏠 Housing Data Analysis using Python

## 📌 Project Overview
This project focuses on exploring and analyzing a housing dataset using Python. The main objective is to understand the relationship between the number of rooms in a house and its median house value through data visualization and statistical analysis.

The project uses data processing and visualization techniques to gain insights from housing data.

---

## 🎯 Objectives
- Load and explore the housing dataset.
- Understand the structure and characteristics of the data.
- Perform basic data analysis using Python libraries.
- Analyze the relationship between total rooms and median house value.
- Visualize data using scatter plots.

---

## 🛠️ Technologies Used

- **Python**
- **NumPy** - Numerical computations
- **Pandas** - Data handling and analysis
- **Matplotlib** - Data visualization
- **Google Colab** - Development environment
